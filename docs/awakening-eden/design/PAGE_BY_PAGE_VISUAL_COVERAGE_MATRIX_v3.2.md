## Global checks on every page

- Exactly one visible footer.
- Exactly one footer logo, using the reversed vector mark on dark backgrounds.
- No public `Benji`; use `Benjy`.
- No public Spotify placeholder; use the confirmed playlist or omit the section.
- No duplicated community photograph.
- No master PNG in production references.
- No Flower/Seed-of-Life substitute.
- No decorative asset creates horizontal overflow at 360, 390, 768, 1024 or 1440 px.
- Decorative images use `alt=""` and `aria-hidden="true"`; meaningful art has honest concise alt text.
- Respect `prefers-reduced-motion` and never rotate the primary logo continuously.
