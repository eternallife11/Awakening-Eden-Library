## 1. Retire the angular simplified mark

The angular / geometric Tree + Heart mark currently used in some small-brand assets is retired from all new Awakening Eden visual work.

Do not use it in:
- new client plans
- PDFs
- posters
- illustrations
- social graphics
- guide covers
- portal compositions
- image generation references
- new website artwork

Existing production references must be replaced safely before any physical asset deletion so the site, favicon, header, footer, manifest and accessibility do not break.

Treat all generated experiments using this angular mark as historical / non-canonical.

## 3. Visual character

Awakening Eden should feel like a living field journal from a regenerative future:
- warm parchment and natural paper
- deep forest and moss greens
- water teal
- terracotta and honey
- rose and lavender accents
- hand ink, watercolor, pigment granulation and tactile botanical detail
- Earth Mama / Rooted Human warmth
- rich Tree of Life imagery
- Mediterranean plants, roots, fungi, water, seeds, flowers and pollinators
- colorful, earthy, alive, human and joyful

Avoid sterile geometric branding, clip-art feeling, neon, glossy 3D, synthetic gradients and generic spiritual decoration.

## 4. Sacred geometry lock

The exact `lotus-of-life-12-exact.svg` remains the only approved sacred geometry.

Never substitute Seed of Life, Flower of Life, hexagonal lattices, generic rosettes or approximate AI geometry.

## 5. Production rule

Use painted portals rarely and with purpose. Use botanicals and field-journal accents to support content, not overwhelm it. Real photography remains the trust layer.

Before deleting any old brand file from the repository, first audit and replace every live reference in HTML, CSS, manifest, favicon, social metadata, build scripts and tests. After replacement and QA, delete only verified-unused superseded assets.
