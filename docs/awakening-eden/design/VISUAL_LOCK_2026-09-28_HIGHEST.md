## 9. Retirement and deletion rule

Retired visual assets must not return to production references.

Before physical deletion:
1. replace every live reference;
2. run the visual-lock guard;
3. build the Cloudflare artifact;
4. run desktop and mobile browser QA;
5. delete only verified-unused retired files.

The CI visual-lock guard is part of the permanent protection against regressions.

## 10. Final filter

Every visual and page decision should ask:

Is it true? Is it practical? Does it serve life? Does it regenerate? Is it beautiful without becoming confusing or heavy? Does it leave people, communities and ecosystems more capable, connected and alive?
