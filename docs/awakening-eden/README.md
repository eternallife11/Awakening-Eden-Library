## Non-negotiable identity rule

The exact twelve-fold Awakening Eden Lotus of Life (`design/lotus-of-life-12-exact.svg`) is the only approved sacred
geometry. Never substitute Seed of Life, Flower of Life, a hexagonal lattice, generic rosette or an AI approximation.
Preserve the Tree + Heart identity. The simplified vector mark (`assets/brand/awakening-eden-mark-*.svg`) is the logo
for header, footer, favicon and small placements — painted portals are threshold art, not logos.

## What is not registered here

The v3.2 package also ships ~20 MB of painted-portal/divider/photo-ornament art (AVIF/WebP/PNG) under its own
`01_ASSETS/`. Only the pieces actually wired into a live page belong in this git repo (see `assets/brand/` for the
vector mark family now used in the header and footer sitewide). The rest of that art stays in the original ZIP
(`~/Downloads/Awakening_Eden_FINAL_SINGLE_SOURCE_Claude_and_Project_Master_v4_2026-08-11.zip`) as a source library —
pull individual pieces in only when a specific route's coverage-matrix item is actually implemented, so production
never ships unused derivatives.
