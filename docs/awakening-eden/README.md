## Non-negotiable identity and geometry rules

The exact twelve-fold Awakening Eden Lotus of Life (`design/lotus-of-life-12-exact.svg`) is the only approved sacred
geometry. Never substitute Seed of Life, Flower of Life, a hexagonal lattice, generic rosette or an AI approximation.

The angular simplified Tree + Heart mark previously used in some header/footer/favicon/small-placement assets is now
**retired from new visual work** by Benjy's 2026-09-09 decision. Do not use it as a reference for new images, client
plans, guides, posters or public artwork. See [`design/VISUAL_LOCK_2026-09-09.md`](design/VISUAL_LOCK_2026-09-09.md).

Existing live references to retired assets must be replaced safely before physical deletion so navigation, favicon,
manifest, social metadata, build scripts and accessibility are not broken. New work should use the richer current
Tree of Life, Earth Mama / Rooted Human, Garden of Harmony, botanical and exact-Lotus visual families named in the
Visual Lock.

## Asset handling

The repository contains current production derivatives, trusted photography, educational boards, botanical dividers,
portal art and some historical or transitional assets. Do not mass-delete the library blindly.

For cleanup:
1. audit every live reference;
2. replace retired visual dependencies with an approved current alternative;
3. run route/build/accessibility QA;
4. delete only verified-unused superseded assets.

This keeps the visual system coherent without breaking the working site.
