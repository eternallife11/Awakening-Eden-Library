Owner direction: Benjy and Sofia, 7 October 2026. Plan only for new generated artwork; the real-photo service-page and copy improvements are implemented separately. Preserve the 3 October visual lock and exact Lotus.

Use the [Living Systems Field Atlas style](../design/LIVING_SYSTEMS_FIELD_ATLAS_STYLE_2026-10-07.md) for every new educational or concept visual in this plan. It defines the painted look, teaching grammar, concept-status labels, mobile layout and review gate.

## Vision
A welcoming illustrated field guide: a visitor understands one relationship, sees a real example and leaves with one doable action. Parchment, forest green, water teal and restrained terracotta. Keep technical labels as editable HTML or SVG; generous type and one lesson per visual. Mystery and beauty belong in the invitation; ecological explanations stay precise.

## Next batch
1. Syntropic agroforestry through time: establishment, management, succession; show temporary support species and their planned removal/pruning. Explain that tropical examples need local adaptation.
2. Orchard renewal: existing tree retained, access protected, compatible understory and soil cover. Label as an illustrative possibility rather than a prediction.
3. Biomass cycling: prunings → surface cover → decomposition → plant uptake. Separate this from wood-filled beds: neither technique is universal.
4. Biopool process diagram only after the actual specialist partner reviews filtration, circulation, safety and maintenance. No claim that plants alone make water safe.
5. Fencing and productive edges: real craft photographs plus a layout showing access, boundaries and wildlife considerations.

## Ready-to-use art brief
“Create a calm botanical educational illustration for Awakening Eden, on warm lightly textured parchment, with forest/soil ink, translucent moss and teal washes and restrained terracotta. Show [one approved ecological relationship]. Mediterranean landscape context. Leave clear spaces for separately typeset labels. No embedded lettering, no logo, no sacred geometry, no glossy effects. This is an educational concept, not a photograph of an actual project.”
Use generated raster artwork only for the illustrative layer. Use SVG/HTML for maps, arrows, technical labels and exact geometry. Never generate a client transformation as documentary proof.

## Social and online learning
Make each approved lesson into a 4:5 social carousel: a question, one diagram, one real photo, one achievable action and a Library link. Use Benjy/Sofia's existing accounts; verify handles before publication. Link to teachers' original work and request permission before reproducing their diagrams. Do not copy another project's visual identity or imply endorsement.
Primary learning references: https://permacultureprinciples.com/permaculture-principles/ and https://agendagotsch.com/en/ . These inform the lessons; practitioner approaches require site context. Feature the existing Library gateways to Films For Action, WaterBear, Farmer's Footprint, Project Biome and ORIGIN.

## Execution order and review
1. Terra implementation pass: prepare the three guide placements and image slots using existing layouts, then add the first approved diagram and real-photo sequence.
2. Generate one illustration at a time using the brief; inspect biology, labels, truthful concept status and the visual lock before producing variations.
3. Technical/reasoning pass for plant combinations, water diagrams, source validation and any conflict or release problem. Model names are preferences, not a claim that a background job exists.
4. Test at 390px and desktop, keyboard access, image sizing, alt text and page weight. Use 960–1440px responsive images, keep diagram labels readable, and offer an enlarged view.
5. Owner review of the first visual sets the direction for the remaining batch. No new infographic generation or changes to guide advice have been done in this pass.

Success: a reader can explain the visual's one idea, choose a next action and identify whether they are seeing a real project, a concept or a general example. Review enquiries and resource use without promising bookings or reach.
