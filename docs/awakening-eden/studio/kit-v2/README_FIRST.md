## The simplest setup
1. KEEP your existing Claude project, live website and originals untouched. Unzip this kit into a new temporary folder in the same project workspace.
2. Ask Claude Code to READ this README, `01_INSTRUCTIONS/CLAUDE_MD_ADDENDUM.md`, and the current repo's `CLAUDE.md`. Do not ask it to blindly overwrite settings.
3. The only thing to add to the current repo's `CLAUDE.md` is the short, compatible routing block in `01_INSTRUCTIONS/CLAUDE_MD_ADDENDUM.md`. Merge manually or with reviewed diffs.
4. Copy `.claude/skills/eden-land-consulting` and `.claude/skills/eden-video-production` into the existing repo's `.claude/skills/` after inspection. Keep the full kit outside the codebase if preferable; skills include their own reference copies.

6. Claude must do ONE stage, test, show artifacts and changes, and STOP until Benjy explicitly approves the next stage. Passing self-tests never implies approval.
7. Work on a branch and keep full-resolution originals plus separate editable overlay geometry. Do not push to the public website or send client assets without authorization.
