# Awakening Eden Video Studio Skill
Read `references/STAGE_APPROVAL_PROTOCOL.md`, `references/PERMANENT_VIDEO_STANDARD.md`, `references/MAP_AND_VISUAL_STANDARD.md`, and `references/VIDEO_RELEASE_CHECKLIST.md` first.

**Never make the whole film in one go without staged approvals.** V0 assets and use case (read only) → V1 creative treatment → V2 script/beat sheet → V3 storyboard → V4 single proof scene/style frames → V5 scenes, one batch at a time → V6 sound/captions → V7 low-res full preview → V8 full render QA → V9 approved publishing copy/upload stage → V10 feedback, each with separate user approval.

Use source footage and audio honestly; no face regeneration or fabricated outcomes, no copyrighted music without rights. Any animated hydrology uses approved map geometry and explicitly conceptual labels. For optional code-created videos check whether Remotion already exists; official skills may be installed only with approval. Render and inspect actual video and stills. Report real errors, then STOP.
